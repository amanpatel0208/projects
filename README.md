# Linear Regression Web App

A Flask-based web application that serves a machine learning linear regression model. 

## Features 
- Accepts user input via a web form.
- Predicts outcomes using a pre-trained scikit-learn Linear Regression model.
- Responsive HTML UI.

## How to Run Locally
1. Clone this repository.
2. Create a virtual environment: `python -m venv venv`
3. Activate it and install dependencies: `pip install -r requirements.txt`
4. Run the app: `python app.py`
